A deterministic paper-trading bot for make.fun's "Pump.fun Replay Sprint — Paper Bot, Real Ranking" bounty. It trades 10 SOL of paper money on a 24h pump.fun replay: confirmed-runner momentum plus dip-reversion, only on established coins (survived ~8+ minutes, 5–85 SOL real reserves, broad buyer base), with small starts, scale-ins into strength only, tight stops and trailing exits. Fully deterministic — no clock, no randomness.

## Run it

```sh
node main.ts
```

The bot speaks agent-fun/replay/v2 on stdin/stdout via the vendored SDK shim (`vendor/makefun-bot.ts`). Grade it locally with the competition kit:

```sh
node cli/makefun.mjs grade-local --kit <kit-dir> --bot . --driver process
```
